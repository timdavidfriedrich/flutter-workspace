# Localization (l10n)

*Requires `SKILL.md`.*

- **Setup:** ARB localization lives in `shared`. `packages/shared/l10n.yaml`:
  ```yaml
  arb-dir: lib/presentation/localization
  template-arb-file: app_en.arb
  output-localization-file: app_localizations.dart
  output-dir: lib/presentation/localization/generated
  nullable-getter: false
  ```
- **New strings:** add the key to **all** ARB files → `cd packages/shared && fvm flutter gen-l10n` → `context.s.<key>`. Never maintain only the template file.
- **Key convention:** `camelCase`, `<feature><Subject><Variant>` — `homeGreetingMorning`, `chatTypeMessageHint`, `profileLanguageLabel`.
  - Global strings without prefix: `cancel`, `close`, `back`, `tryAgain`, `error`.
  - Error messages with `error` prefix: `errorConnection`, `errorNotFound`, `errorApi`.
  - Suffixes for UI roles: `...Label`, `...Hint`, `...Message`, `...Title`, `...Button`.
- **Placeholders** always typed via `@` metadata:
  ```json
  "errorApi": "Error while communicating with the server: {message}.",
  "@errorApi": { "placeholders": { "message": { "type": "String" } } }
  ```
- **Plural/select** via ICU syntax, not Dart `if` chains.
